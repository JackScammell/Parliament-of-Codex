# Codex Port Status

Version 0.3.0 completes the defined Codex-native contract: 15 skills explicitly
define all 66 legacy action aliases, 33 roles cover analysis/implementation and
read-only review, and dependency-free local tooling supplies safe snapshots,
validated telemetry/metrics, retention, and exact project status.

The port intentionally uses qualified skills, native subagents, root governance,
and the canonical artifact graph rather than reproducing Claude-specific hooks
or plugin-data variables. Replay compares evidence and decisions; it does not
claim deterministic language-model output. Installation guarantees skills, not
automatic portability of project-scoped agent TOMLs.

Optional future integrations include user-configured connectors/automations and
an API deliberation sidecar only if measured need justifies them. They are not
required for the 66 documented aliases and are never claimed as configured.
